# 华为云竞赛提交标准对照（2026 华为开发者大赛·智能体创新赛-昌吉学院站）

> 来源：官方页面实抓（developer.huaweicloud.com/competition/information/1300000374）。
> 赛程：**作品提交截止 2026-11-20（当前剩 3 天）**；每队每天最多提交 1 次，最终成绩取**最近一次**提交版本；决赛 12-02。

## 一、提交规范（官方原文要点）

- 打包为 **zip**，命名规范：**作品名称+队伍名称+版本号+联系方式**（作品名尽量简洁，不要包含汉字状态下的符号）
- 大小 **≤ 200MB**（当前仓库 84MB，含视频，安全但需注意最终打包体积）
- 提交入口：大赛官网"提交作品"Tab 上传，完成后可查看提交状态

### zip 内必须包含 5 部分

| 官方目录 | 内容要求 | 当前仓库对应 | 状态 |
|---|---|---|---|
| `ppt/` | 整体介绍 PPT 或 PDF：场景背景、功能架构、核心亮点、**码道应用说明** | `presentation/`（PPTX+PDF 混放） | ⚠️ 需重组：拆出 ppt/ 目录；确认 PPT 含"码道应用说明"章节 |
| `project/` | 作品 Demo，可演示完整功能 | backend/ + frontend/ + run.sh + requirements.txt | ✅ 内容齐，需按目录整理 |
| `video/` | 功能演示视频，完整核心功能操作流程，**建议 ≤3 分钟**，可提交文件或在线链接 | `presentation/PV-Clean-Decision-演示视频.mp4` | ⚠️ 需拆出 video/ 目录 |
| `codearts_proof/` | 码道使用证明：AI 交互对话过程文档、代码生成/重构/排错过程记录 | `codearts_proof/`（8 份 md） | ✅ 已按官方口径准备 |
| `readme/` | 环境依赖+一键安装脚本、部署运行步骤、开源组件说明、**码道在项目开发中的应用总结** | `readme/README.md` | ⚠️ 需补"码道应用总结"与"开源组件说明"核对；旧六 Agent 章节需修订（见审查报告 P1-12） |

**结论：内容资产基本齐备，但目录结构必须重组打包（presentation/ 拆为 ppt/ + video/），并补 readme 两节内容。**
