## 二、启动方式（已验证）

五件套结构下的启动方式：

```bash
cd project && bash run.sh   # 端口 8001
```

任意工作目录均可启动（路径基于 `__file__`）。Windows 启动方式：

```cmd
cd project && run.bat
```

或双击 `project/start.bat`。前端开发调试见 `project/frontend/README.md`。
