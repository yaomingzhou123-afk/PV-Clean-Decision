# 码道使用痕迹总览（codearts_proof）

本项目（疆光 · 光伏电站沙尘清洗决策 Agent）全程使用华为云码道（CodeArts）开发。本目录按官方评分点组织留存，全部内容来自真实开发过程，无事后编造。

## 与官方规范的对照

| 官方要求 | 对应文件 |
|---|---|
| 功能开发阶段 AI 交互对话过程的文档记录 | 01、02（含关键 Prompt 与决策对话） |
| 代码生成、重构、排错的过程记录 | 03、04 |
| AI 原生流程覆盖度：需求分析→生成→测试→部署 | 01→03→05→07 |
| Prompt 质量 | 01、02、03 中标注的原始指令 |
| 测试记录 | 05 |
| 数据真实性验证 | 06 |
| 部署 | 07（沙箱部署记录待补） |

## 文件清单

- 00_总览与规范依据.md（本文件）
- 01_需求分析与选题记录.md
- 02_架构设计记录.md

- 05_测试与验收记录.md

## 截图要求（由团队成员完成）

screenshots/ 目录需包含以下真实截图，评审用于核对 md 记录：

1. 码道会话中发起需求分析的界面截图
2. 代码生成过程的界面截图（含文件树与 diff）
3. 测试运行界面截图（pytest 输出）
4. 应用运行界面截图（演示模式 + 实时模式各一张）

截图必须来自真实操作，禁止使用编辑过的图片。
