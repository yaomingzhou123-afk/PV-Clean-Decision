日期：2026-11-15（V3.0 第四阶段）
原则：所有公式、单位、参数来源、假设与限制如实声明；不编造模型精度、不伪造置信概率；无传感器数据时输出一律标注"模型估算"。

## 一、污损估算模型（三层）

### 第 1 层 · 环境风险层（`assess_environment`）

分析数据中实际存在的环境因子，缺失字段在 `data_completeness` 中如实标注，不虚构：

| 因子 | 来源 | 单位 | 用途 |
|---|---|---|---|
| PM10 | Open-Meteo Air Quality（48h 预报均值） | μg/m³ | 污损速率增量输入 |
| PM2.5 | 同上 | μg/m³ | 环境证据展示 |
| 沙尘 dust | 同上 | μg/m³ | 环境证据展示（>50 时列入驱动因素） |
| 降雨 | Open-Meteo Forecast（3 天预报） | mm | 自然清洁判断 |
| 无有效降雨天数 | 以"距上次清洗天数"代理 | 天 | 积灰累积代理（**限制**：无历史降雨观测，可能高估） |
| 风速 | 同预报（请求参数 m/s） | m/s | 作业安全判断 |
| 温度 | 同预报 | °C | 仅展示，不参与决策 |

### 第 2 层 · 污损估算层（`estimate_soiling`）

**本项目无污损传感器，输出为模型估算（`method: "model_estimate"`），不得当作实测污损率展示。**

```
日污损速率 = base_rate_per_day + max(0, PM10 − pm10_ref) × pm10_factor
污损损失率 = min(max_loss, 日污损速率 × 运行天数 × tilt_factor)
```

| 参数 | 默认值 | 单位 | 来源/假设 |
|---|---|---|---|
| base_rate_per_day | 0.004 | /天 | IEA PVPS Task 13 / NREL 干旱区研究区间 0.1–0.5%/天，取保守值 0.4%/天 |
| pm10_ref | 80 | μg/m³ | PM10 影响基准 |
| pm10_factor | 0.00035 | （/天)/(μg/m³) | 依据公开研究趋势标定，**待实测修正** |
| max_loss | 0.15 | 无量纲 | 封顶防外推失真 |
| tilt_factor | 1.0 | 无量纲 | **未启用修正**：倾角影响自清洁，但缺乏实测依据，默认 1.0 并如实标注 |

### 第 3 层 · 证据层（随 `soiling` 输出）

- `drivers`：主要影响因素（PM10 超基准、沙尘浓度、运行天数、自然清洁预期）
- `data_completeness`：pm10 / pm2_5 / dust / 预报天数 / 温度是否可用
- `param_basis`：引用 `pv_config.json` 的 `sources` 参数依据
- `limitations`：模型限制（非实测、线性累积假设、无雨天数代理、倾角未修正）

## 二、经济性模型

**统一时间范围**：全部计算基于 `horizon_days`（默认 14 天）评估期，口径唯一，不重复计收益。

```
理论日发电量(MWh/日) = 装机容量(MW) × E_d(kWh/kWp)          [PVGIS 历史气候]
                     = 装机容量 × 日辐照(kWh/m²) × 系统效率    [降级公式]

有效可恢复损失 = 污损损失率 × recovery_efficiency × (1 − 降雨自然清洁折减)

日增量收益(元) = 理论日发电量 × 有效可恢复损失 × 1000 × 电价
评估期增量收益(元) = 日增量收益 × horizon_days
清洗总成本(元) = 人工 + 用水 + 设备（分项模式）或 包干成本（lump_sum 模式）
停机损失(元) = 理论日发电量 ÷ 24 × 停机小时 × 电价 × 1000
净收益(元) = 评估期增量收益 − 清洗总成本 − 停机损失
回本期(天) = 清洗总成本 ÷ 日增量收益
```

| 参数 | 默认值 | 来源/假设 |
|---|---|---|
| recovery_efficiency | 0.95 | **经验假设**：顽固沉积无法完全清除，待实测校准 |
| rain_clean_effect | 0.3 | **经验假设**：预报期内有 ≥2mm 降雨时，不清洗也会被自然清洁一部分，清洗增量收益按 30% 折减 |
| rain_clean_threshold_mm | 2.0 | 有效自然清洁降雨阈值，经验值 |
| downtime_hours | 4 | 停机时长假设 |
| price_per_kwh | 0.25 | 新疆燃煤标杆上网电价政策值 |
| cleaning_cost | 4000 | 公开招标区间参考，待以实际合同价替换 |

**口径说明（避免重复计算）**：清洗收益按"增量"口径——不清洗时损失持续存在，清洗后从零重新积灰，两相抵消后增量 ≈ 当前损失 × 评估期；若预报有雨，不清洗路径会被自然清洁部分恢复，故乘 (1 − rain_clean_effect) 折减。

## 三、天气与安全约束

```
weather_block = (未来48h降水 ≥ rain_limit_mm) 或 (最大风速 ≥ wind_limit_ms)
interval_block = 距上次清洗 < min_clean_interval_days（14 天）
```

- **阈值全部由配置决定**（`pv_config.json` 的 `safety` 节），不宣称适用于所有电站的统一行业标准
- 数据过期判断：`fetched_at` 随每条数据输出，前端展示拉取时间
- 数据不足判断：见下

## 四、四种决策结果

| action | 含义 | 触发条件（优先级从高到低） |
|---|---|---|
| `insufficient_data` | 数据不足，暂时无法判断 | 有效预报 <2 天；PM10 缺失；**live 模式下数据降级为样例**（不基于模拟数据给真实决策） |
| `defer` | 建议等待天气窗口 | weather_block |
| `hold` | 暂不建议清洗 | interval_block 或 净收益 ≤ 0 |
| `clean` | 建议清洗 | 以上全部不满足 |

`insufficient_data` 时协商短路（orchestrator 直接输出评审主席意见并结束），不启动多 Agent 协商。

## 五、敏感性分析（`sensitivity_analysis`）

**方法：单因素确定性敏感性分析（`one_factor_deterministic`）。非蒙特卡洛，无概率分布假设，不输出任何编造的置信概率。**

每次仅扰动一个参数并完整重算净收益与决策，共 12 个场景：

| 参数 | 扰动 |
|---|---|
| 电价 | ±20% |
| 清洗成本 | ±20% |
| 污损速率 | ±20%（base_rate 与 pm10_factor 同比） |
| 恢复效率 | 1.00 / 0.90 |
| 发电水平 | ±20%（系统效率代理） |
| 降雨自然清洁 | 效果=0 / 效果=0.6 |

输出：每个场景的净收益、决策、是否翻转（`flips_decision`）。

## 六、模型限制总声明

1. 无污损传感器实测，污损率为模型估算
2. 线性累积假设，未建模沙尘事件突发性
3. 无历史降雨观测，无雨天数以运行天数代理
6. 恢复效率与降雨清洁效果为经验假设，待实测校准
7. 未考虑组件类型（双玻/背板）与局部遮挡差异
8. 敏感性分析为确定性单因素，不构成概率意义上的风险量化
