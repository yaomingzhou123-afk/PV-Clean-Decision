# SIMULATION_LAB · 清洗决策模拟实验室

日期：2026-11-16（V3.0 第六阶段）

## 一、定位与边界

模拟实验室用于让评委/用户现场改变光伏电站参数，观察污损风险、发电损失、清洗成本、收益、回本周期、天气风险和推荐决策如何变化，并对照三种清洗策略。

**所有结果都是模拟计算结果**：

- 输入来自用户当前填写的假设，或界面明确标注的“示例假设”。
- 没有接入真实历史发电、真实清洗工单或真实电力交易数据。
- 因此结果只能称为“模型模拟比较”，**不能称为真实回测、真实收益或真实电站运行结果**。
- 页面顶部、结果区和 API 响应都带有 `simulation` / `模拟计算结果` 标注与免责声明。

实现位置：

| 文件 | 作用 |
|---|---|
| `backend/simulation_lab.py` | 参数校验、统一计算装配、三策略模拟、影响曲线、示例场景 |
| `backend/main.py` | `GET /api/simulation/defaults`、`POST /api/simulation/calculate` |
| `backend/pv_model.py` | 复用现有污损/发电/经济公式；新增可选 `soiling_override_ratio` |
| `backend/data/pv_config.json` | 项目阈值、污损/经济默认参数；PM2.5 演示系数默认关闭 |
| `frontend/index.html` | “模拟实验室”标签页、参数表单、结果卡片、策略表、影响图表、场景保存 |
| `backend/tests/test_simulation_lab.py` | 参数变化、负收益、安全条件、非法输入、策略对照与 API 测试 |

项目采用的安全/约束阈值（来自 `pv_config.json`，不是行业统一标准）：

- 风速安全阈值：12 m/s。
- 未来 48 小时降雨阈值：1.0 mm。
- 最小清洗间隔：14 天。
- 污损模型上限：15%。
- 自然清洁降雨阈值：2.0 mm；自然清洁折减：30%。

## 三、计算方法

### 1. 复用确定性模型

实验室不另写一套收益公式，而是把参数装配成与主决策相同的 `config` / `context`，调用 `pv_model.compute_metrics(..., include_sensitivity=False)`。因此：

- 理论日发电量：`装机容量 × 日辐照 × 系统效率`（实验室使用降级公式，不使用 PVGIS）。
- 污损损失率：`min(上限, 日污损速率 × 天数 × 倾角因子)`。
- 日污损速率：`基础速率 + max(0, PM10 − 80) × PM10 系数 + max(0, PM2.5 − 35) × 0.00005（模拟实验室演示系数）`。
- 有效可恢复损失：`污损损失率 × 恢复效率 × (1 − 自然清洁折减)`。
- 日增量收益：`理论日发电量 × 有效可恢复损失 × 1000 × 电价`。
- 净收益：`日增量收益 × 评价周期 − 清洗总成本 − 停机损失`。
- 停机损失：`理论日发电量 ÷ 24 × 停机小时 × 电价 × 1000`。

`soiling_override_ratio` 只用于模拟实验室：它把当前污损估计替换为手动假设值，但仍走同一套经济公式；输出同时保留 `model_loss_pct` 供对照，避免把假设值伪装成模型结果。

### 2. 两个明确的演示映射

以下两项没有实测依据，只为让参数影响可见：

1. **倾角-积灰映射**：以 35° 为参考，`tilt_factor = clamp(1 − 0.15 × (倾角 − 35) / 25, 0.85, 1.15)`。
2. **倾角-发电量映射**：以 35° 为参考，`tilt_energy_factor = clamp(1 − 0.25 × |倾角 − 35| / 35, 0.75, 1.0)`。

界面和 API 都标注“演示假设，不得作为工程结论”。如果要做真实工程评估，必须用现场实测或组件厂商数据替换。

### 3. 单次清洗测算与策略模拟的口径差异

上方 KPI 的“预计清洗收益 / 净收益 / 回本周期”是**当前时点单次清洗测算**，沿用主决策模型的经济口径，假设评价周期内只清洗一次。

下方三策略表是**逐日策略模拟**：

- 收益 = `(不清洗基线损失 − 策略损失) × 理论日发电量 × 电价 × 1000`，即相对“不清洗基线”的模型模拟收益。
- 成本 = 清洗次数 ×（清洗总成本 + 单次停机损失）。
- 净收益 = 策略收益 − 策略成本。
- 两种口径不能直接相加；页面和本文档都明确提示这一点。

### 4. 三种策略

三种策略使用相同输入、相同评价周期、相同污损日速率和相同成本：

| 策略 | 触发方式 | 是否考虑天气 | 是否考虑经济性 |
|---|---|---|---|
| 固定周期清洗 | 距上次清洗达到固定周期即安排 | 记录不安全计划，不执行违规清洗 | 否 |
| 污损阈值清洗 | 污损损失达到阈值即安排 | 记录不安全计划，不执行违规清洗 | 否 |
| 天气与经济收益联合决策 | 污损达到阈值 + 天气安全 + 单次清洗净收益为正 | 是 | 是 |

逐日模拟规则：

- 每日先按日污损速率累积，再判断当天是否安排清洗。
- 清洗后污损损失按恢复效率折减（0.95 表示保留 5% 残留）。
- 预计降雨达到 2 mm 时，按 30% 自然清洁折减，并同时作用于基线与策略。
- 固定周期/阈值策略若计划落在风速或降雨超限日，计入 `unsafe_attempts`，不执行清洗。
- 联合策略在天气不安全时跳过，计入 `weather_skips`；不会安排不安全清洗。
- 固定周期短于 14 天时，提示可能与项目最小清洗间隔冲突。

输出字段：清洗次数、预计发电收益、清洗成本、净收益、回本周期、安全风险、决策理由、评价周期、初始污损、日污损速率。

### 5. 参数影响曲线

后端对以下参数做单因素扫描，每个点都重新调用同一套计算：

- PM10、PM2.5、上网电价、清洗总成本、恢复效率、连续无雨天数、预计降雨、装机容量、组件倾角。

返回每个点的 `net_gain / action / loss_pct`。前端用这些实际重算结果生成 SVG 折线图，不在前端写死数值。当前页面展示 PM10、电价、清洗总成本、连续无雨天数四条曲线；其余参数曲线也在 API 响应中，便于后续扩展。

## 五、API

### `GET /api/simulation/defaults`

返回：

- `result_kind = "simulation"`
- `disclaimer`
- `params`：默认参数
- `specs`：每个参数的 key/label/unit/min/max/step/default/description/basis
- `scenarios`：三个示例场景
- `thresholds`：项目安全/约束阈值
- `assumptions` / `limitations`

### `POST /api/simulation/calculate`

请求示例：

```json
{
  "pm10": 80,
  "pm2_5": 24,
  "dry_days": 20,
  "capacity_mw": 20,
  "tilt_angle_deg": 35,
  "price_per_kwh": 0.25,
  "labor_cost": 2000,
  "water_cost": 1000,
  "equipment_cost": 1000,
  "expected_rain_mm": 0,
  "wind_speed_ms": 9,
  "recovery_efficiency": 0.95,
  "horizon_days": 30,
  "fixed_cycle_days": 30,
  "soiling_threshold_pct": 5,
  "scenario_name": "自定义模拟场景（模拟）"
}
```

返回：`summary`、`metrics`、`strategies`、`impact`、`warnings`、`assumptions`、`limitations`、`formulas`、`disclaimer`。

非法输入由 Pydantic 返回 422；跨字段提示（如固定周期短于最小间隔、PM2.5 演示系数）放在 `warnings` 中。

## 六、页面使用

1. 打开首页，点击“模拟实验室”标签。
2. 页面加载后自动拉取默认参数并计算一次。
3. 修改任一参数，停止输入约 350 ms 后自动重算；也可以点“重新计算”。
4. “恢复默认”恢复 17 个参数的默认值。
5. 顶部三个按钮加载示例 A/B/C，结果区明确显示“示例假设”。
6. 页面内可保存当前参数为本地模拟场景（localStorage），场景名自动加“模拟 ·”前缀；可选下拉加载。
7. 三策略表高亮净收益最高的策略；负净收益不显示回本周期。
8. 图表由 `/api/simulation/calculate` 返回的 `impact` 数据生成。

## 八、已知局限

1. **无真实历史数据**：不能称为真实回测，也不能把模拟净收益当作真实收益承诺。
2. 污损为线性模型估算，未建模沙尘事件突发性、组件类型、局部遮挡和清洗工艺差异。
3. 倾角-积灰、倾角-发电量、PM2.5 增量均为演示假设，没有实测标定。
4. 策略模拟为日粒度，未建模具体作业时段、班组调度、清洗用水限制和分区清洗。
5. 降雨只按“首日降雨假设”简化，未使用逐小时气象预报。
6. 电价、清洗成本、恢复效率均为输入假设，不代表实际合同或行业标准。
7. 评价周期与固定周期/阈值参数可调，但不同参数组合可能产生极端结果；界面会给出风险提示，仍需人工复核。
8. 本实验室不替代现场检测、安全交底和真实运维决策。

## 九、答辩口径

- “这不是真实回测，是模拟实验室；我们用同一套确定性模型让评委现场改变参数，观察结果如何变化。”
- “污损没有传感器实测，是 `model_estimate`；手动覆盖值会明确标注 `user_assumption`。”
- “倾角和 PM2.5 的影响是演示假设，已在界面和文档标注，不作为工程结论。”
- “三种策略使用相同输入和相同评价周期；收益是相对不清洗基线的模拟值，不能与单次测算直接相加。”
- “负净收益不会推荐清洗；天气不安全不会推荐立即清洗；非法输入会明确提示。”
